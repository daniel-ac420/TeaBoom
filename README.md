# TeaBoom

# Тестовое задание: Карточка товара
Реализация верхнего блока карточки товара

## 🔗 Живое превью
Посмотреть работающий вариант можно на GitHub Pages:
https://daniel-ac420.github.io/TeaBoom/

## 🛠 Запуск проекта
Проект написан на чистом стеке БЕЗ использования сборщиков и сторонних библиотек
* **Локальный запуск:** Открыть файл index.html в браузере

## ⚙️ Что сделано
* **CSS & Структура:** Вёрстка на Grid/Flexbox, адаптив до 320px включительно (на мобильных карусель переключается в нативный свайп). Цвета вынесены в переменные в :root
* **Графика:** Все иконки сделаны на SVG
* **Ванильный JS:** Динамическая смена цен и артикулов при выборе веса, круговая карусель превью, модальное окно Zoom
